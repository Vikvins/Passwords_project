# Password generator & validator

## Описание
Приложение на C# WinForms для генерации и проверки паролей  
Пользователь может создавать безопасные пароли с различными параметрами, проверять их надёжность по 10-балльной шкале и копировать готовый пароль в буфер обмена

---

## Функционал
1. **Генерация пароля**
   - Настройка длины пароля
   - Включение/отключение:
     - Заглавных букв (A-Z)
     - Цифр (0-9)
     - Спецсимволов (`!@#$%^&*()-_=+`)
     - Русских букв
   - Пароль гарантированно содержит хотя бы один символ из выбранных категорий
   - Отображается под кнопкой "Сгенерировать пароль" после её нажатия

2. **Проверка надёжности**
   - По 10-балльной шкале:
     - Длина, наличие заглавных/строчных букв, цифр, спецсимволов
     - Проверка на повторяющиеся символы подряд
     - Проверка на последовательности (`123`, `abc`)
     - Минимум уникальных символов

      ## Критерии оценки пароля (10-балльная шкала)
      | №  | Критерий                                    | Условие для получения балла           | Баллы |
      |----|--------------------------------------------|-------------------------------------|-------|
      | 1  | Длина пароля                                | ≥ 8 символов                         | 1     |
      | 2  | Длина пароля                                | >= 12 символов                        | 2     |
      | 3  | Длина пароля                                | >= 16 символов                        | 1     |
      | 3  | Наличие строчных букв (a–z)                 | Хотя бы одна строчная буква (латиница или кириллица)           | 1     |
      | 4  | Наличие заглавных букв (A–Z)               | Хотя бы одна заглавная буква (латиница или кириллица)         | 1     |
      | 5  | Наличие цифр (0–9)                         | Хотя бы одна цифра                     | 1     |
      | 6  | Наличие спецсимволов                        | Хотя бы один спецсимвол (`!@#$%^&*()-_=+`) | 1     |
      | 7  | Нет повторяющихся символов подряд          | Нет одинаковых символов подряд        | 1     |
      | 8  | Нет последовательных символов              | Нет последовательностей типа `123`, `abc`, `абв` | 1 |
      | 9  | Минимум уникальных символов                 | Количество уникальных символов ≥8    | 1     |
      | 10 | Длина                                       | >= 25 символов                       | Сразу 10 | 
       
   - Цветовая подсветка:
     - 0–3 → красный (слабый)
     - 4–6 → оранжевый (средний)
     - 7–8 → синий (хороший)
     - 9–10 → зелёный (сильный)

2. **Копирование пароля**
   - Кнопка «Копировать в буфер обмена»


---

## Использование
1. Выбрать длину пароля
2. Отметить нужные галочки для генерации
3. Нажать «Сгенерировать пароль»
4. Для проверки собственного пароля:
   - Ввести пароль
   - Нажать «Проверить надёжность»
   - На экран будет выведена оценка с цветовой подсветкой
5. Для копирования пароля — нажать «Копировать»
